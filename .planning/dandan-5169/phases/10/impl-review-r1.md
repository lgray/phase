## Findings

**[MED]** [behavior] The collapse licence misses mass-move filters whose zone comes from the effect's `origin`, so "exile all opponents' graveyards" does not take the whole pile in Dandan. Evidence: `crates/engine/src/game/effects/change_zone.rs` `owner_scoped_nonbattlefield_mass_filter` rewrites `Typed{controller: Opponent, properties: []}` into `Owned{Opponent}` with no `InZone`, so `claimed_shared_zone` (`game/filter.rs`) returns `None` and `zone_axis_admits` keeps one comparison. Dynamic probe (scratch copy of 6f59a8e449, hand-built `ChangeZoneAll{origin Graveyard, destination Exile, target Typed{controller Opponent}}` resolved by P0 over a pile holding a P0-owned and a P1-owned card): Dandan exiles only the P1-owned card, `(mine exiled, theirs exiled) = (false, true)`; Standard gives the same pair, so the shared-pile format is not collapsed on this path. Population: walk over `client/public/card-data.json` x `coverage-data.json` (supported) for effects with `origin` Graveyard/Library whose `target` is a Typed filter with a controller or `Owned` axis and no `InZone`/`InAnyZone` naming that origin: 10 cards (Kaya's Guile, Mnemonic Betrayal, Release to Memory, Szat's Will, Phyrexian Scriptures, Author of Shadows, Disciple of Perdition, Elspeth's Nightmare, Hedonist's Trove, plus Campfire's command-zone filter which is irrelevant); the plan's walk W counted only filters that carry `InZone` ("typed controller Opponent with InZone Graveyard/Library: 0"), so this population was never measured. Why it matters: Disposal Mummy (V3) already asserts the pile is "an opponent's graveyard" for every seat; the same phrase on a mass effect leaves the caster's own pile cards unexiled, and the charter's Phase 10 deferral list is "None outstanding", so nothing owns the gap. No Dandan-list card is in the 10, which makes this a class hole, not an acceptance-floor failure. Suggested fix (one seam): in `owner_scoped_nonbattlefield_mass_filter`, when it moves `controller` into `Owned`, also push `FilterProp::InZone { zone }` for the single origin zone (the function already receives `origin_zones`; skip when more than one), so the filter makes the zone claim the licence reads; test = the probe above as an integration row on a real card (Release to Memory or Kaya's Guile) with the Standard twin, red at 6f59a8e449.
