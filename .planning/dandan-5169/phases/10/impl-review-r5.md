Probe (scratch git-archive of 9287a640b9, own target): (a) unit, Dandan, P0 creature on the battlefield, filter `controller: You`, claim `[Battlefield, Graveyard]` and `[Graveyard, Battlefield]` -> `[true, true]` (must be `[true, false]`, battlefield control is a per-seat fact). (b) effect level through the real handler: Dandan, `ChangeZoneAll { origin: None, destination: Hand, target: TrackedSetFiltered { Typed{Creature, controller: You} } }`, tracked set = {P0 graveyard creature, P1 battlefield creature}, source controller P0 -> BOTH cards go to hand (`PROBE dandan: grave=Hand opp_perm=Hand`); the opponent's permanent is taken by "creatures you control". Control: the same two probes pass with `claimed_shared_zone` reverted to its 5148aafffb form (`zone != Battlefield && claimed.contains(&zone)`), so the delta introduces it; Standard has no shared zone and cannot collapse. Population: supported cards with a `ChangeZone`/`ChangeZoneAll` target whose collected `InZone`/`InAnyZone` zones include Battlefield and Graveyard/Library AND a controller/`Owned` Typed leaf lacking its own `InZone` (jq walk over `client/public/card-data.json` x `coverage-data.json` supported): 0 (control: the same walk without the axis predicate names Decree of Annihilation and Ultimate Nullification); `TrackedSetFiltered` containing a controller/`Owned` Typed leaf under a `ChangeZone`/`ChangeZoneAll` target in supported cards: 0 (control: 210 `TrackedSetFiltered` nodes in card-data). Zero supported cards, so latent, but reachable by the production handler with a runtime-built set and it is the exact over-admission the round was asked to hunt. Why it matters: `claimed_zones` carries two meanings (scan zones, where a Battlefield member is genuinely in a scanned zone; the single zone an entrant left, on the trigger seam), and the new rule is only right for the second. Suggested fix: license a battlefield resident only when the claim names no Battlefield (`if claimed.contains(&Zone::Battlefield) { None } else { first non-Battlefield claim }`); add `[Battlefield, Graveyard]` and `[Graveyard, Battlefield]` -> OWNER_ONLY rows to `a_claimed_origin_licenses_a_battlefield_resident_on_the_live_door` (both red at 9287a640b9 per probe (a)), and the (b) tracked-set row to change_zone tests (red at 9287a640b9, green at the fixed rule; its Dandan reach leg is the graveyard card reaching Hand).
