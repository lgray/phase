## Findings

### F1 [behavior] The occurrence-count relation is not the CR 613.8a relation on a type line, and regresses a case the base gets right
Plan, Design: "the count changes exactly when Y removes or creates an occurrence of `X.from`" and Step 2 / item 1 "`apply_to_permanent_text` (type-line subtype match counts one)". False for a type line that already holds `X.from` when Y rewrites onto it: `apply_to_permanent_text` collapses the subtype set after the rewrite, so Y's creation of a second `X.from` is invisible to the count.
Evidence (scratch, count prototype vs base): an Island card given base subtypes `[Island, Swamp]` (a shock/dual/triome land type line), A=Island->Swamp, B=Swamp->Forest, both cast orders.
- base: AB `["Forest"]`, BA `["Forest"]` (B depends on A through the word-pair arm in both orders).
- count prototype: AB `["Forest"]`, BA `["Swamp","Forest"]`.
Counts at the decision point: B's count is 1 before and 1 after A (collapse), A's count is 1 before and after B, so no edge and timestamp order applies. Derived reading (CR 613.8a(b), "what it does to any of the things it applies to"): A turns "Island Swamp" into a second Swamp, so B (all instances of Swamp) now rewrites two instances; B depends on A and the result is `["Forest"]` in either order. The plan therefore introduces a cast-order-dependent result on every land type line carrying two basic land types, a class Magical Hack/Crystal Spray target directly.
Required revision: the preview must measure instances before the set collapse (the preview rewrite of the type line keeps duplicates, or the count is taken over the pre-dedupe list), and the Design principle sentence must say so. Add a Verification Matrix row: two-basic-type recipient, A=Island->Swamp and B=Swamp->Forest in both cast orders asserting `["Forest"]` (derived from CR 613.8a(b) as above), with the guard "only A cast ends `["Swamp"]`" and a mutation (count after dedupe) that turns it red. Sibling class check: the command `git grep -n 'retain\|dedup\|HashSet' -- crates/engine/src/game/text_substitution.rs` lists the one dedupe site in the rewrite authority (the `seen` HashSet `retain` in `apply_to_permanent_text`, type line; the other `retain` removes the intrinsic mana ability); keywords, abilities and definitions do not dedupe, so the type line is the single member.
