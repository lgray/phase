## Shape of the code (derived, confirmed by one entry-point trace)

Stated by the module header of `game/text_substitution.rs` ("CR 612 ... read by the Layer 3 pre-pass for battlefield permanents and by the resolution seam for spells on the stack") and the doc on `WORD_CARRIERS` ("the single authority for CR 612.2 'used in the correct way'"). Parts and owners: the **parsers** (`parser/oracle_effect/conditions.rs` ability side, `parser/oracle_trigger.rs` trigger side) decide which typed condition a phrase becomes; the **carrier table** `WORD_CARRIERS`, keyed by (nearest serialized `type` tag, field key, word domain), alone decides whether a color string at a position is a word; the **rewriter** (`TextSubstitution::rewrite_counted`, reached by `restamp_resolving_spell_text` -> `rewrite_resolved_ability` for spells and `apply_to_permanent_text` for permanents) only consults the table; the **evaluators** (`game/effects/mod.rs` `AbilityCondition::ManaColorSpent`, `game/triggers.rs` `TriggerCondition::ManaColorSpent`) compare the condition to the object's recorded payment tally and never see text. Trace driven: `stack.rs` restamp -> `restamp_resolving_spell_text` -> `rewrite_counted` -> `carrier_class(Some("ManaColorSpent"), "color", ColorWord)`.

## Decision (the charter's branch, decided by claims 2 and 3)

Carrier = `SYMBOL`; both word-form emitters are deleted; no discriminator. The charter's "reachable word emitter -> discriminator" branch is not taken because the only reachable emitter is a hand-written duplicate of the single condition authority (`parse_inner_condition`, CLAUDE.md "Trigger and static parsers must delegate to it") whose word-form text already re-parses (claim 3) to the generic `OfColor` shape the table classifies as a Word; deleting it leaves `ManaColorSpent` symbol-only, so the table is exact over the parsers' emissions. Ladder: rung 1 (nothing to do) fails by claim 1; rung 2 (the repository's authority already parses the word form) holds; a typed discriminator would be rung 7 and would add a serialized field to two enums, a protocol bump, and a sibling-field read in `walk_strings` while keeping a duplicate emitter alive. Estimated mechanism: one table line plus deletions (net negative production lines). No serialized shape changes: both `ManaColorSpent` variants are untouched, so no protocol constant, wire version or binding changes; printed-card ASTs are unchanged (claim 2), so the parse-diff and coverage signatures show nothing.
