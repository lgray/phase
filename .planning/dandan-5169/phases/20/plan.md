## Decision

Provenance is a typed, closed, nested payload: one new enum `SpentColor { ColorWord { color }, ManaSymbol { color } }` (`#[serde(tag = "type")]`, `Copy`, in `types/ability.rs` beside `CastManaSpentMetric`) replaces the bare `color: ManaColor` on BOTH `AbilityCondition::ManaColorSpent` and `TriggerCondition::ManaColorSpent` (`ManaColorSpent { color: SpentColor, minimum }`), with `SpentColor::color()` for the evaluators. The table holds two plain rows keyed by the leaf's own nearest tag — `carrier(Some("ColorWord"), "color", COLOR, W)` and `carrier(Some("ManaSymbol"), "color", COLOR, SYMBOL)` — and the old `("ManaColorSpent", "color")` row is deleted (that position is an object now, not a string leaf).

Why nested rather than a sibling `form` field (decided by reading `walk_strings`): the walker passes the visitor the nearest `type` tag, the key and the leaf and nothing about siblings, and all three consumers (`classified_word_occurrences`, `unclassified_word_positions`, `rewrite_counted`) classify through `carrier_class(tag, key, domain)`. A sibling field needs a new context channel in the walker, a new table dimension or `WordClass`, and a change at three visitor sites; the nested tag is read by the existing mechanism with no walker or table-shape change.

Measured on a prototype of this design: `cargo check -p phase-engine --lib` finishes clean with exactly seven production files edited (`types/ability.rs`, `game/text_substitution.rs`, `parser/oracle_effect/conditions.rs`, `parser/oracle_trigger.rs`, `game/effects/mod.rs`, `game/triggers.rs`, `game/coverage.rs`); the `{ .. }` and `color: _` destructures (`ability_scan.rs`, `ability_rw.rs`, `assembly.rs`, `oracle_effect/mod.rs`, `types/ability.rs`) compile unchanged; `carrier_census_classifies_every_word_position_and_round_trips` passes.

Required field, no `#[serde(default)]`: a default would hide an emitter that forgot to set provenance; the export and the committed fixture are regenerated, and an in-flight serialized condition of the old shape failing to load is the standing alpha-save break.

Emitters set it (population: `rg -n "ManaColorSpent *\{" crates/engine/src` outside tests; none deleted): `parse_symbolic_mana_color_spent_condition` (single and `And` leaves) -> `ManaSymbol`; `parse_word_mana_color_spent_condition` (shadowed fallback) -> `ColorWord`; `try_extract_adamant_condition` -> `ColorWord`; `SymbolicManaSpentIntro::condition` (single and `And` leaves; the `Not` wrapper carries them) -> `ManaSymbol`. Evaluators read `color.color()`; the paid-tally comparison is untouched and ignores provenance.

Ladder (three lines). Task: make the spend condition remember whether its color was printed as a word or a symbol, so the text-change rewrite spares symbols. By hand: set a field in the parser, read it in the carrier table. Rung 2 holds: the table already classifies by nearest tag, and a tagged payload is read by that mechanism unchanged; rung 1 fails (claim 1), rungs 3-4 have no tool for a typed provenance, and a sibling field fails rung 2 (it needs a walker channel).

Variant Discoverability: `cargo engine-inventory` was run in W (838 enums, 5993 variants) and searched for enum names matching word/symbol/provenance/lexical/surface/form/origin/printed: the matches are other axes (`AbilityProvenance`, `ReplacementOrigin`, `MayTriggerOrigin`, `TextWordDomain` = the word classes a change can name, `CastManaSpentMetric::OfColor` = the generic word-form metric); none expresses how a color is written. Serialized-tag collision over all variant names: `ColorWord` exists only as the unit variant of `TextWordDomain` (a plain string, never an object tag); `ManaSymbol` is not a variant name (`ManaSymbolCount` is a different key). `add-engine-variant` stages: (1) DOES_NOT_EXIST; (2) EXTEND_OK — two variants of one axis, no sibling is added to a parent enum; (3) WITHIN_SECTION (CR 612.2 with CR 107.4); serialized-surface audit is Steps 6-8.
