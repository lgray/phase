## Pattern Coverage

Class: every format whose rules depart from the stock rules on zone ownership, draw order, mulligan procedure, hand-entry ownership, opening-hand value or match structure. `GameFormat` today answers these questions implicitly (in `mulligan.rs`, `draw.rs`, `deck_loading.rs`, `engine.rs`, the AI) by literal format checks or by not being asked at all; after this phase each is a typed axis with a stock answer that every existing format and every `Custom(_)` returns, so the next shared-pile or variant-mulligan format adds one arm per axis, not code in the consumers. Charter attribution: Dandan is the one shipped consumer; this phase covers zero cards by itself by construction (registration infrastructure); the phases that read the axes cover the 23-card list.

## Extension vs Creation

Extends: the exhaustive-axis pattern (six more methods), the fixed-deck constructor pattern, the frozen-lobby-floor pattern (#9226), the registry/mirror pattern, the shared constructed validator. Creates: five small axis types in `format.rs` (needed because each axis has a distinct question and a typed answer; none duplicates an existing type — inventory-checked) and the one `manabrew-compat` refusal. Deviation from the charter's wording (reasoned): the charter and brief name a new `quick_dandan_check` / `evaluate_dandan` pair "mirroring Momir's". Momir's pair exists because Momir validates a fixed *composition* (12 of each snow basic). Dandan's pile is engine-supplied in Phase 6 and the player never submits one, so the only rules to enforce are the ones the axes already carry (exactly 80, no sideboard, no commander slot, copy limit, pool), which `evaluate_constructed`/`quick_constructed_check` read from `FormatConfig` with `CardPoolAuthority::for_format(Dandan) == AdmitsEveryCard`. A Dandan-specific pair would restate that function line for line. The brief's requirement ("read axis methods, not literals") is met by routing, and no Dandan composition check is added (an 80-Islands submission is accepted exactly as a Freeform 80-Islands list is; the submitted list is never loaded for a `supplies_fixed_deck` format).
